## Description (EN)

ScoutX supports football scouting and match planning with a shared team workflow.

With ScoutX, scouts can review matches, coordinate plans with teammates, document observations, and continue work with structured follow-ups.

v1 core features:
- Discover matches and add them to a personal plan
- Team feed to see which scout plans or has already seen which game
- Mark observations as "seen" and trigger follow-up actions
- Link match reports and observation notes in team context
- Add manual/unofficial games plus tournament/national-team imports
- Export via iOS Share Sheet (PDF/file exports)

ScoutX is designed for reliable team operations: role-based permissions, transparent feed events, and clear scouting lifecycle states.
