# ScoutX App Store Screenshot And Submission Checklist

Stand: 2026-05-17

## Screenshot Sets

- iPhone 6.9" (required if targeting latest iPhones):
  - Setup/Filter
  - Games with plan action
  - Team Feed with seen status
  - Observation follow-up action
  - Export/Share flow
- iPad 13" (if iPad family is enabled):
  - Dashboard overview
  - Team coordination/feed view
  - Games planning view

## Screenshot Rules

- Use production-like team/account names (no test junk).
- No placeholder lorem text.
- No internal debug/admin controls visible.
- UI language consistent with selected ASC locale.
- All legal links valid in submitted metadata.

## App Review Attachments

- Reviewer account credentials (team role + password).
- Short test script aligned with Review Notes.
- Optional demo video for complex feed/planning flow.

## Metadata Consistency Checks

- App name/subtitle match DE+EN metadata docs.
- Keywords do not duplicate brand name.
- Description does not claim unsupported features.
- Privacy URL and support URL reachable.
- Age rating answers match in-app behavior.

## Final ASC Submission Pass

1. Upload localized metadata (DE, EN).
2. Upload screenshots for each required device class.
3. Fill privacy questionnaire from `docs/scoutx_app_store_privacy_labels.md`.
4. Paste reviewer notes (DE/EN as needed).
5. Submit internal TestFlight build and run smoke checklist once.
